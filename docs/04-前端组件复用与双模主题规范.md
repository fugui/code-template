# 04 - 前端组件复用与双模主题规范 🎨

本文梳理 `@code/common` 前端公共组件库的标准用法，并详解团队强制执行的**亮色（Light）/ 暗黑（Dark）双模主题适配规范**、**Flat BEM 样式准则**与**通用分页标准**。

---

## 1. 严守双模主题与 Design Tokens 单一事实源

CodeBench 门户顶栏支持随时切换 **亮色模式**（根节点挂载 `.light-theme`）与 **暗黑模式**（`:root` 默认）。子模块样式必须全部引用 `code-common/frontend/src/styles/theme.css` 中的 `--color-*` 语义变量：

### 1.1 标准语义变量映射表

| 视觉层级 | 必须使用的 CSS Token | 典型适用元素 | 严禁出现的错误写法（反例） |
| :--- | :--- | :--- | :--- |
| **应用底层背景** | `var(--color-bg-app)` | 页面最外层画布 | `#0f172a`、`#f8fafc` |
| **主表面 / 卡片** | `var(--color-bg-surface)` | 卡片、侧边栏、顶栏、弹窗主体 | `#1e293b`、`#fff`、`#ffffff` |
| **次级底色 / 表头** | `var(--color-bg-muted)` | `thead` 表头、参数行、代码底块 | `#111827`、`rgba(255,255,255,0.05)` |
| **表单输入底色** | `var(--color-bg-input)` | 输入框、下拉框、文本域 | `#000`、`#fff` |
| **悬停交互反馈** | `var(--color-bg-hover)` | 表格行 `:hover`、菜单项 `:hover` | JS `onMouseEnter` 改 DOM style |
| **主要文本** | `var(--color-text-primary)` | 标题、正文、重要数值 | `#f8fafc`、`#111827`、`black` |
| **次要说明文本** | `var(--color-text-secondary)` | 副标题、列表辅助列、字段说明 | `#94a3b8`、`#666` |
| **弱化提示文本** | `var(--color-text-muted)` | 占位说明、底部提示、分组小标题 | `#64748b`、`#999` |
| **彩色实心按钮文字** | `var(--color-text-white)` | `.btn-primary` / `.btn-danger` 内部文字 | 直接继承导致亮色下变黑字 |
| **主边框 / 弱分割线** | `var(--color-border-primary)` / `var(--color-border-subtle)` | 卡片外框、表格行分割线 | `1px solid #334155` |

### 1.2 样式抽象与 Flat BEM 三原则
1. **禁止 JSX 静态内联样式**：布局、间距、字号、边框、颜色一律抽离至 `.css` 文件，仅允许真动态计算值（如实时百分比进度条 `width: `${pct}%``）使用 `style`。
2. **禁止 JS 模拟伪类**：严禁通过 `onMouseEnter` / `onMouseLeave` 修改元素样式，统一使用原生 CSS `:hover`、`:active`、`:focus-visible`。
3. **扁平化模块命名空间**：建议统一以 `.code-<模块缩写>-<元素>--<修饰符>` 命名（如模板中的 `.code-tpl-nav-link--active`），既清晰自解释，又防止在微前端同 DOM 树下与其他子模块类名互相污染。

## 2. 优先复用 `theme.css` 内置全局工具类

在手写自定义 CSS 前，优先直接使用 `@code/common` 已全局注入的标准原子与组件样式类：

* **卡片容器**：`.code-card`、`.code-card-glass`
* **指标统计卡**：`.code-stat-card` + `.code-stat-icon` + `.code-stat-label` + `.code-stat-value`
* **数据表格**：`<table className="code-table">`（自带表头底色、行分割线与鼠标悬停高亮）
* **表单控件**：`.code-input`、`.code-select`、`.code-textarea`
* **按钮系统**：`.btn` 搭配 `.btn-primary` / `.btn-secondary` / `.btn-danger` / `.btn-outline` / `.btn-text`，小尺寸追加 `.btn-small`
* **状态徽章**：`.code-badge` 搭配 `.code-badge--primary` / `--success` / `--warning` / `--danger` / `--purple` / `--orange` / `--muted`
* **栅格与弹性布局**：`.grid-cols-2`、`.grid-cols-3`、`.grid-cols-4`、`.flex-between`、`.flex-center`、`.gap-sm`、`.gap-md`

## 3. `@code/common` 核心组件与 Hooks 速查手册

> 完整实战代码请直接参考 `frontend/src/pages/ItemListPage.tsx`。

### 3.1 通用分页标准（`Pagination` + `usePagination`）
团队强制要求所有分页列表遵守以下规范：
* **URL 状态同步**：`page`、`pageSize` 与搜索筛选参数必须同步至 URL Search Params（支持浏览器前进/后退与链接分享）。
* **默认条数与阶梯**：默认 **`25` 条/页**，下拉选项固定为 **`[15, 25, 50, 100]`**。
* **极简 5 页滑动窗口**：不显示 `...` 省略号或跳页输入框，直接使用 `<Pagination />` 组件即可自动渲染合规结构：

```tsx
import { Pagination, usePagination } from '@code/common';

// 自动从 URL 读取 ?page=1&pageSize=25
const { page, pageSize } = usePagination({ defaultPageSize: 25 });

// 渲染在表格底部（非受控模式下自动将翻页与切页条数写回 URL Search Params！）
<Pagination totalItems={total} defaultPageSize={25} pageSizeOptions={[15, 25, 50, 100]} />
```

### 3.2 侧滑抽屉表单（`Drawer`）
支持 `'sm' | 'md' | 'lg' | 'xl' | 'full'` 宽度预设、ESC 关闭与多级浮层 `z-index` 栈自动管理：

```tsx
import { Drawer } from '@code/common';

<Drawer
  open={drawerOpen}
  onClose={() => setDrawerOpen(false)}
  title="新建业务条目"
  subtitle="副标题说明文案"
  width="md"
  destroyOnClose
  footer={
    <div className="code-tpl-drawer-footer">
      <button type="button" className="btn btn-secondary" onClick={() => setDrawerOpen(false)}>取消</button>
      <button type="submit" form="item-form" className="btn btn-primary">保存提交</button>
    </div>
  }
>
  <form id="item-form">{/* 表单字段 */}</form>
</Drawer>
```

### 3.3 二次确认弹窗（`useConfirm`）与轻提示（`useToast`）
> **安全红线**：严禁在业务代码中使用阻塞主线程的原生 `window.alert()`、`window.confirm()` 或 `window.prompt()`！

```tsx
import { useConfirm, useToast } from '@code/common';

const confirm = useConfirm();
const { showToast } = useToast();

const handleDelete = async () => {
  const ok = await confirm({
    title: '确认删除记录',
    content: '删除后不可恢复，是否继续？',
    confirmText: '确认删除',
    type: 'danger', // 'danger' | 'warning' | 'info'
  });
  if (!ok) return;

  await apiRequest(`/items/${id}`, { method: 'DELETE' });
  showToast('删除成功', 'success'); // 'success' | 'error' | 'warning' | 'info'
};
```

### 3.4 成员检索选择器（`MemberSearchSelect`）
自动对接 `/api/users` 与 `/api/me`，支持姓名/工号防抖搜索与“快捷选择我自己”：

```tsx
import { MemberSearchSelect } from '@code/common';

<MemberSearchSelect
  value={ownerId}
  onChange={(selectedUserId) => setOwnerId(selectedUserId)}
/>
```

### 3.5 状态标签（`StatusTag`）与空状态占位（`EmptyState`）
* `<StatusTag status="success" text="生效中" size="sm" />`（`status="running"` 时自动附带呼吸脉冲动效）。
* `<EmptyState inTable colSpan={8} type="search" title="未找到匹配结果" />`（支持 `data`、`search`、`permission`、`success`、`error`、`folder` 六种预设插画）。
